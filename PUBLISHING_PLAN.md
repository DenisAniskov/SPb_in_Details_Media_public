## Как выполнить передачу бинарных файлов

Для точного переноса без перекодирования используйте исходный архив `SPb_in_Details_Publication_Ready_Media_Package_v1.0.zip`, подготовленный в рабочем сеансе, либо его распакованную копию. Загружайте **отдельные файлы с сохранением путей**, а не только ZIP архив целиком. Для больших медиа удобнее Git LFS или отдельные релизные вложения; GitHub не рекомендует хранить множество тяжёлых файлов в обычной истории.

После загрузки выполните сверку по `SOURCE_SHA256SUMS.txt` (это контрольные суммы исходного пакета; текстовые файлы README/PUBLISHING_PLAN репозитория имеют актуализированные редакции).
