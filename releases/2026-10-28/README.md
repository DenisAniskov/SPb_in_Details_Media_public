# Петербург в деталях — утверждённые материалы, 28.10.2026

**Статус:** частичное зеркало утверждённого комплекта FINAL. В эту папку добавлены **12 из 16** подготовленных публичных файлов. Исходный медиапакет v1.0 остаётся в своих прежних каталогах, с исходными контрольными суммами.

## Файлы, ещё не перенесённые в GitHub

Более крупные файлы пока сохранены владельцем вне репозитория: горизонтальный ролик **FINAL v1.5** (MP4), редактируемая маркетинговая презентация **FINAL v1.1** (PPTX), технический паспорт **FINAL v1.1** (DOCX) и маркетинговый паспорт **FINAL v1.1** (DOCX). Передача через подключённый GitHub API прерывалась на этих файлах. **Не считайте публичное зеркало полным до их загрузки и проверки.**

## Достоверность изображений

Ролик FINAL с реальными скриншотами использует **архивные экраны приложения 1.0.0+1**, а не запись интерфейса действующего релиза. Опубликованный Android APK — **1.1.1+3**. Скриншоты отмечены как архивные. При подготовке внешних публикаций не выдавайте их за кадры из актуального приложения. Следуйте [правилам использования материалов](../../MEDIA_RIGHTS.md).
