# Загрузка медиапакета в GitHub

Публичный репозиторий: https://github.com/DenisAniskov/SPb_in_Details_Media_public

**Статус: текстовая часть уже опубликована.** Большие бинарные файлы из полного пакета пока не переданы через подключение, поскольку оно не поддерживает отправку локальных MP4/PDF/ZIP как содержимого файла.

## Наиболее простой способ

1. Скачайте локальный **Media Transfer Bundle** из чата ChatGPT и распакуйте его.
2. Установите Git и Python 3, если их нет. Настройте авторизацию GitHub для обычного `git push` (например, через Git Credential Manager или GitHub Desktop). **Не вставляйте токены в чат или файлы медиапакета.**
3. В терминале в папке с распакованным пакетом выполните:
   ```powershell
   python publish_media.py --verify
   python publish_media.py --push
   ```
4. Скрипт сверит контрольные суммы **всех 29 файлов исходного пакета**, скопирует **только публичные материалы** и создаст ветку `media-v1.0-assets` в репозитории. README, юридические документы и статус публикации на `main` сохранятся.
5. После успешного push будет показана ссылка `compare/main...media-v1.0-assets`. Откройте PR и проверьте 25 файлов в целевых каталогах. После merge можно заменить отметку STAGING на RELEASED.

**Без запуска `--push` никакие сетевые изменения не выполняются.** Параметр `--verify` только проверяет исходный архив.

Не помещайте школьную работу или материалы защиты в этот публичный репозиторий.

## Что проверить после merge

- MP4 открываются, субтитры совпадают с роликами, QR ведёт на официальный Android-релиз v1.1.1.
- Файлы в `brand/`, `documents/`, `presentation/`, `press/`, `print/`, `videos/` совпадают с оригиналом по SHA-256.
- Отдельно обновите README и RELЕASE_FACTS.json со статусом RELEASED, а сайт — через PR в website dev.
