## 1. Суть продукта

«Петербург в деталях» — Android-приложение для пешеходного знакомства с Санкт-Петербургом. Оно соединяет карту и маршрутизацию Яндекса, редакционный каталог городских мест, подбор прогулок по интересам, сопровождение по маршруту и справочные дополнительные инструменты. Продукт помогает выбирать не только конечную точку, но и то, что интересно увидеть по дороге.

**Основной пользовательский сценарий:** найти место или выбрать интересы → составить или построить пешеходный маршрут → увидеть маршрут на карте → следовать подсказкам и узнавать о городе. При желании пользователь обращается к ИИ-помощнику, голосовому поиску и расчётным оценкам условий прогулки.

**Продуктовые принципы:** отсутствие обязательной регистрации; опора на документированные источники; явное сообщение об ограничениях; контроль согласий на использование внешних сервисов; локальное хранение избранного и предпочтений.

## 3. Реализованные возможности

| Блок | Фактическая реализация | Важная граница |
| --- | --- | --- |
| Карта | Официальный Yandex MapKit Full SDK 4.45.0 | Для карты и маршрутов требуется подключение к сети и действующий клиентский ключ |
| Каталог | **180** редакционно отобранных мест с категориями, фильтрами и описаниями | Не полный перечень объектов города; данные о входе, доступности и времени работы не гарантированы |
| Исторические справки | **35** подготовленных исторических карточек в backend | Наличие подробной исторической справки зависит от места |
| Внешний поиск | Адресные подсказки, геокодирование и обратное геокодирование через backend и сервисы Яндекса | Найденная точка не становится частью редакционного каталога |
| Пешеходная маршрутизация | Построение маршрута между двумя точками; дистанция, длительность, геометрия от MapKit | Не общественный транспорт; backend не строит геометрию пешеходных маршрутов |
| Навигация | GPS-сопровождение, инструкции поворотов, обнаружение ухода с маршрута | Перестроение по действию пользователя; без фоновой навигации |
| Smart Walk | Детерминированный подбор мест с учётом интересов и бюджета времени | Подбор не является ИИ-генерацией; окончательная геометрия — MapKit |
| Scenic-приоритет | Учитывает локальный набор пешеходных пространств, набережных и площадей | Приоритет не гарантирует «самый красивый» путь |
| Shade | Расчёт геометрической тени от зданий по времени | Не учитываются все деревья, рельеф и неизвестные высоты |
| Quiet | Относительная оценка дорожного шума по OSM | Не измеряет шум в децибелах |
| Puddle | Модельная склонность участков к лужам | Не прогнозирует фактические лужи в конкретной точке |
| Pollen | Модельные концентрации пыльцы на основе CAMS/Open-Meteo | Не медицинская оценка и не измерение в точке |
| ИИ-помощник | Вопросы о городе и каталоге через backend → OpenRouter; поддерживается SSE | Может ошибаться; доступность определяется оператором и бесплатными моделями |
| Голос | Системное Android-распознавание речи и Android TTS | Качество и сетевой режим зависят от устройства и системных служб |
| Избранное | Локальное хранение сохранённых мест и настроек | Нет аккаунта и синхронизации между устройствами |

**Операционная оговорка:** серверные интеграции и отдельные модельные движки могут быть отключены оператором или недоступны из-за квот/поставщика. В таком случае продукт должен сообщать о недоступности, а не подставлять вымышленные результаты.

## 4. Высокоуровневая архитектура

```text
Пользователь Android
        │
        ▼
Flutter / Dart + Material 3
  ├── экраны, Provider, локальные настройки
  ├── Yandex MapKit ─── карта, точки, пешеходный маршрут
  ├── GPS / Android Speech / Android TTS
  └── HTTPS API (Dio)
              │
              ▼
       FastAPI backend
  ├── каталог и исторические справки ──► SQLite
  ├── Smart Walk ─────────────────────► каталог
  ├── Shade / Quiet / Puddle / Pollen ─► OSM и модельные данные
  ├── поиск ──────────────────────────► Яндекс Geocoder / Suggest
  └── ИИ-помощник / SSE ──────────────► OpenRouter

Отдельно: статический сайт Astro → GitHub Releases (официальный APK)
```

**Ключевое разделение ответственности:** Яндекс MapKit строит пешеходный маршрут; FastAPI хранит каталог, подбирает места и *оценивает предоставленную геометрию*. Ни сайт, ни backend не заменяют пешеходный маршрутизатор MapKit.

## 5. Android-клиент

### 5.1. Стек и устройство кода

- **Flutter 3.47.6 / Dart 3.13.5**; интерфейс Material 3.
- **Provider** для состояния; **Dio** для HTTP; **shared_preferences** для локальных настроек и избранного.
- **yandex_maps_mapkit 4.45.0** — официальный Full SDK, включая PedestrianRouter.
- **geolocator** — координаты устройства; Kotlin-мост — обращение к системному распознавателю речи; **flutter_tts** — системная озвучка.
- Android/Kotlin, **JDK 21**, Gradle wrapper 8.14.3, target API 36.

Основные каталоги приложения: `lib/ui/` (экраны), `lib/providers/` (состояние), `lib/services/` (карта, навигация, помощник, голос), `lib/data/` (модели, репозитории, локальные редакционные данные), `test/` (unit/widget/integration).

### 5.2. Конфигурация и жизненный цикл сборки

Для запуска нужны `MAPKIT_API_KEY`, `API_BASE_URL`, `APP_ENV`. В debug возможен локальный `.env.dev`, который не коммитится. Release/profile требуют явно переданной конфигурации и HTTPS-адреса backend; без постоянного keystore подписи сборка release отклоняется. Клиентский ключ MapKit потенциально извлекается из APK; его безопасность определяется прежде всего ограничениями у Яндекса. Серверные ключи Geocoder/Suggest и OpenRouter в APK не передаются.

Публичный репозиторий предназначен для воспроизводимой проверки и самостоятельной сборки, но **не содержит** рабочие ключи, секреты подписания или гарантии готового доступа к внешним сервисам.

## 6. Backend

### 6.1. Серверный стек

- **FastAPI**, Python **3.14.x**, Pydantic-схемы и асинхронный слой SQLAlchemy 2.0 + SQLite/aiosqlite.
- Один процесс / один worker и постоянный том для записываемой SQLite-базы. Для развёртывания используются Docker и Railway.
- Встроены проверка входящих схем, ограничения размера и времени запроса, лимиты внешних вызовов, учёт квот, безопасная обработка ошибок и контроль происхождения датасетов.
- `/health` проверяет процесс, `/ready` — готовность; документация OpenAPI в исходной конфигурации открывается только в режиме `development`.

### 6.2. Основные HTTP-контракты

**Базовый префикс:** `/api/v1`, форматы ответов — JSON, для потокового ИИ — SSE.

| Метод / путь | Назначение |
| --- | --- |
| `GET /places`, `/places/categories`, `/places/{id}` | Каталог, категории, карточки |
| `GET /places/{id}/history` | Историческая справка, если есть |
| `POST /routes/propose-walk` | Подбор последовательности объектов по предпочтениям |
| `POST /routes/evaluate` | Зарезервированный контракт; **не реализован** |
| `POST /environment/shade/analyze` | Расчётная тень на готовой геометрии |
| `POST /environment/quiet/analyze` | Относительный дорожный шум |
| `POST /environment/puddle/analyze` | Относительная вероятность мокрых участков |
| `POST /environment/pollen/analyze` | Модельная концентрация пыльцы |
| `GET /search/suggest`, `/search/geocode`, `/search/reverse-geocode` | Внешний поиск Яндекса |
| `POST /assistant/chat`, `/assistant/chat/stream` | Текстовый ИИ-ответ / SSE |
| `GET /assistant/capabilities` | Доступность помощника |

Контракты включают строгие ограничения входа, коды ошибок (`400`, `404`, `408`, `413`, `414`, `422`, `429`, `503`) и сообщение о недоступности источника вместо выдуманной оценки. Вызывающие внешние API компоненты по умолчанию имеют управляемые оператором флаги доступности.

### 6.3. Данные и эксплуатация

Каталог — **180** мест, в backend имеются **35** исторических справок. SQLite хранит каталог и служебный учёт попыток/квот; снимки данных для расчётных движков открываются только на чтение. Оператор отвечает за постоянное хранилище, резервные копии, HTTPS на краю сети, квоты и конфигурацию внешних поставщиков. Публичный репозиторий содержит проверяемый снимок исходников, но не рабочую базу и не секреты production.

## 9. Приватность и безопасность

**Модель приватности:** аккаунты и обязательная регистрация отсутствуют. Избранное, пользовательские настройки темы/голоса и принятые согласия остаются на устройстве. Приложение не ведёт фоновое отслеживание и не сохраняет историю перемещений. В официальном сайте отсутствуют аналитические и рекламные трекеры.

**Передача данных:** координаты пешеходной маршрутизации передаются Yandex MapKit; поисковые запросы — backend и далее Яндексу; геометрия маршрута для расчётных оценок — backend; текст и контекст ИИ-вопроса после отдельного согласия — backend, OpenRouter и выбранному поставщику модели. Распознавание голоса выполняется системным сервисом Android, который может использовать собственную сетевую обработку. Поэтому формулировка «ничего не отправляется третьим лицам» **недопустима**.

**Технические меры:** ключи серверных API остаются на сервере; ограничены размеры запросов, частота и параллелизм; ошибки не раскрывают внутренние трассировки/ключи; приложение требует отдельного согласия для ИИ и системного распознавания. Использование ассистента рассчитано на модели OpenRouter с маркировкой `:free` и серверными ограничителями; бесплатность и постоянная доступность внешней модели не гарантируются.

## 11. Известные ограничения: обязательны при коммуникациях

1. **Только Android и пешеходные маршруты.** Транспортные маршруты и офлайн-карты отсутствуют.
2. **Маршрут зависит от сети и MapKit.** Реальный GPS и картографические сервисы зависят от устройства, ключа, сети и внешнего поставщика.
3. **Без автоматического перестроения и фоновой навигации.** Отклонение обнаруживается, но перестроение запускает пользователь; прибытие подтверждается вручную.
4. **Модельные показатели ≠ измерения.** Тень, тишина, влажность поверхности и пыльца не гарантируют фактическую обстановку и безопасность.
5. **Каталог ограничен 180 местами.** Это редакционная выборка; адреса из поиска Яндекса могут иметь меньше сведений.
6. **ИИ не подтверждает факты.** Ассистент может ошибаться и быть временно недоступен. Его нельзя описывать как экспертный или всезнающий.
7. **Нет автоматических обновлений.** Пользователь самостоятельно загружает APK из GitHub Releases.
8. **Не заявлена завершённая полевая сертификация.** CI и сборки не подтверждают полное тестирование MapKit/GPS/голоса на всех устройствах.
